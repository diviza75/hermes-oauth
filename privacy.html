Hermes Privacy Policy

Hermes is a private personal assistant operated by and for a single user (diviza75@gmail.com). It is not offered to any other users.

Data accessed

With the owner's consent, Hermes accesses the owner's Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts data solely to perform tasks requested by the owner.

Use and sharing

Data is used only to provide these personal features. It is not sold, shared with third parties, or used for advertising. OAuth tokens are stored on the owner's own server.

Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
